The engine plays the competition control — 120 seconds plus 0.5 per move — and divides it with the submission's own formula: tournament is what that formula asks for, budget what it is allowed here. The two differ because the submission is compiled and searches on a dedicated core, where six seconds buys real depth; in a browser tab it would only buy a long wait, so the ceiling is 6s soft and 11s hard. The shape is unchanged — the middlegame still gets more than the endgame, and a settled move still leaves early. Your own clock counts up but is not enforced.

Contempt

A repetition scores 24cp below zero, so the engine declines one it could take while anything better is on offer — and still accepts the draw when every alternative is worse. It is on, as it is in the submission: worth +10.5 ± 14.8 Elo over 2,120 games.

Moves

Where the tables came from

Every piece–square value was fitted rather than borrowed. The starting point was textbook material only — 100/320/330/500/900, no per-square structure — and Texel’s method supplied each deviation from self-play positions labelled offline.

How changes were judged

Nothing shipped because it looked right. Each candidate played its predecessor under SPRT until the result was decided, at thousands of games per test, and lost the argument if it could not win the match.

What it does on its own clock

The competition build thinks while the opponent does, predicting the reply from the transposition table and searching the position it expects next. The prediction lands about four times in five.

One setting, and it is the competition one. There is no difficulty menu: the engine plays the clock it will actually be given — 120 seconds plus 0.5 per move — and divides it with the submission's own formula, spending about five and a half seconds on an opening move and abandoning any search that runs past three times that. What differs is speed, not settings. The submission is Python compiled with numba on a dedicated core, and it thinks on its opponent's clock as well; this is JavaScript in a browser tab with no pondering, so the same seconds buy fewer ply, and the per-move budget is capped a little under what the formula asks for. It shares the tuned tables, the search, the contempt and the time management — beating it here is not the same as beating the submission.
